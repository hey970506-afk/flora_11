# 可控分支合并冲突演示

本文件用于《开源文化运动》作业中的真实Git操作演示。
冲突由同一维护者有意修改同一行构造，不代表有两位同学参与。

演示文本：花序是一款在本地浏览器中记录并有序管理个人日常待办的清单。

## 实际操作记录

1. 从main创建docs/usage-clarity分支，完善README的撤销说明，提交后正常合并到main。
2. 从main创建demo/wording分支，修改上述演示文本并提交。
3. 返回main，修改同一行并提交；合并demo/wording时，Git实际报告内容冲突。
4. 阅读两侧内容，将“本地个人清单”与“有序排列”的表述合并为现在的说明，移除冲突标记，再提交合并结果。

本演示由同一维护者执行，目的在于理解分支差异和冲突解决，不计作同学协作。实际提交编号以Git日志为准。
