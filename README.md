# 花序 flora_11

一个以花叶线条装饰的日常任务清单。无需安装、联网或登录，直接打开 `index.html` 即可使用。

项目仓库：[hey970506-afk/flora_11](https://github.com/hey970506-afk/flora_11)。[直接在线使用](https://hey970506-afk.github.io/flora_11/)，也可下载源码并打开本地文件。任务保存在当前浏览器，不上传到服务器。

## 功能

- 添加任务，名称最多100字，截止日期可留空。
- 纸色日期面板支持切换年月、选择今天和清除日期；方向键移动日期，Esc收起面板。
- 按截止日期排序，无日期的事项置后，已完成事项排在待办之后。
- 勾选完成或恢复待完成，显示今天截止和逾期状态。
- 编辑名称与日期，隐藏或显示已完成事项。
- 每条任务右侧都有独立的“心情”入口，可选记录开心、疲惫、焦虑或平静。选好后原位置显示线描表情与文字，直接点击即可更换或清除；编辑窗口也支持修改，不选择不影响使用。
- 任务以花苞表示待办；勾选后逐渐绽放，取消完成时收拢。状态立即保存，绽放结束后再调整排序。系统选择减少动态效果时直接显示最终状态。
- 点击任务左侧花苞下方的“完成”即可标记完成，展开后显示“已完成”；再次点击恢复待办。悬停时也会显示操作提示。
- 删除任务，每项删除后8秒内可撤销；连续删除可倒序逐项撤销。
- 使用浏览器localStorage保存任务。

## 打开与试用

用Edge或Chrome打开 `index.html`，记录一项无日期任务、一项今天截止任务和一项过去日期任务。依次尝试完成、编辑、删除和撤销，再刷新并关闭重开，检查任务是否保留。

心情记录的是自己选择时的感受，完成任务不会自动改变心情。每条任务分别选择，新任务默认为未标记，修改某一条不会影响其他任务。旧版没有心情字段的任务会按未标记读取。

删除后可以继续添加或完成其他任务，撤销入口独立保留；连续删除时，按最近删除的顺序逐项撤销，每项各有8秒时限。建议先用不重要的测试事项熟悉这一操作。

请使用同一浏览器及同一浏览器用户；本地文件尽量保持原路径，在线版保持同一网站地址。本地文件与在线版不会自动共享记录。清除浏览器数据、移动文件、更换浏览器或使用隐私模式，可能使原记录无法访问。当前没有云端同步、数据导出或到期通知；逾期提示仅在页面内显示。

## 设计与协助说明

视觉借鉴新艺术风格的线条与配色，以及[《秘密花园》作者官网](https://www.johannabasford.com/books/secret-garden/)展示的植物线描方向。当前装饰由SVG代码构成，未打包书中图片。字体仅按系统字体名调用，没有复制或分发字体文件。早期生成的人物插画已从当前网页移除。

项目代码、文档和检查工作有AI辅助；维护者负责需求、视觉反馈与是否采用修改的判断。已知缺陷与未完成的验证应继续公开记录。
